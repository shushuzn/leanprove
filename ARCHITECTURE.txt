================================================================
                    模运算推论 (Modular Corollaries)
================================================================

  基于 prime_ge_five_mod_six (p%6 ∈ {1,5}):

  ┌──────────────────────────────────────────────────────────┐
  │  prime_sq_mod_twelve                                     │
  │  p^2 ≡ 1 (mod 12)                                       │
  │  证明: p%6∈{1,5} -> p%12∈{1,5,7,11} -> p^2%12=1        │
  └──────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────┐
  │  prime_sq_sum_mod_24                                     │
  │  p^2 + q^2 ≡ 2 (mod 24)  (p,q >= 5 素数)               │
  │  证明: p^2≡q^2≡1(mod24) -> (p^2+q^2)%24 = 2            │
  └──────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────┐
  │  prime_sq_sum_mod_8                                      │
  │  p^2 + q^2 ≡ 2 (mod 8)   (p,q >= 5 素数)               │
  │  证明: p^2≡q^2≡1(mod8) -> (p^2+q^2)%8 = 2              │
  └──────────────────────────────────────────────────────────┘

================================================================
                    辅助引理 (Helper Lemmas)
================================================================

  sub_one_sub_sub_one:  (a-1)-(b-1) = a-b   (用于素数平方差)
  sq_sub_one_eq_mul_pm1_aux: a^2-1 = (a-1)(a+1) (用于四次幂)
  mod6_to_mod24:  p%6 -> p%24 枚举          (用于平方和模24)
  sq_mod24_of_residue: x^2%24=1 for x∈{1,5,7,11,13,17,19,23}
  sq_mod8_of_odd:  x^2%8=1 for x∈{1,3,5,7}
