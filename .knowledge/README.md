# Leanprove RAG 知识库

本目录存储项目证明过程中积累的知识，用于提高后续证明效率。

## 文件结构

- `mathlib-api.md` - Mathlib API 用法记录
- `proof-patterns.md` - 证明模式和技巧
- `project-structure.md` - 项目结构和依赖关系
- `sorry-inventory.md` - 当前 sorry 清单和进展
- `cast-patterns.md` - Lean 4 cast 系统处理模式
- `fourier-transform.md` - Fourier 变换相关 API

## 使用规则

1. 每次证明成功后，将关键 API 用法和技巧记录到对应文件
2. 每次遇到困难并解决后，将解决方案记录到 `proof-patterns.md`
3. 更新 `sorry-inventory.md` 跟踪进展
4. 证明前先查阅相关知识文件
